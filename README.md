# 나의 일기장 — 설치 안내서

갤럭시 Z 플립6에서 앱처럼 쓰는 개인 일기장이에요. 인터넷 없이도 쓰고 볼 수 있고, 기록은 휴대폰 안에만 저장돼요.

---

## 0. 먼저 알아 두기

- 앱 **코드**는 인터넷 주소(웹사이트)에 올려야 설치할 수 있어요. 무료 서비스인 GitHub Pages를 쓰면 HTTPS 주소가 자동으로 생겨요.
- **일기·사진은 그 웹사이트에 올라가지 않아요.** 내 휴대폰 안에만 저장돼요. 그래서 저장소를 '공개(Public)'로 만들어도 일기는 아무도 볼 수 없어요. 공개되는 건 이 폴더의 프로그램 파일뿐이에요.
- 한 번 정한 주소는 바꾸지 마세요. 주소가 바뀌면 휴대폰은 다른 앱으로 인식해서 기존 기록이 보이지 않아요(이럴 땐 백업 파일로 복원하면 돼요).

---

## 1. 웹에 올리기 (GitHub Pages, 무료)

PC로 하면 가장 쉬워요. 휴대폰만으로도 할 수 있어요(아래 '휴대폰만으로 올리기' 참고).

1. **github.com**에 들어가 오른쪽 위 **Sign up**으로 가입해요. (이미 계정이 있으면 로그인)
2. 오른쪽 위 **＋** 버튼 → **New repository**를 눌러요.
3. **Repository name**에 `my-diary`라고 적고, **Public**을 고른 뒤 아래 **Create repository**를 눌러요.
4. 다음 화면에서 파란 글씨 **uploading an existing file**을 눌러요.
5. 받은 `my-diary.zip`의 압축을 풀고, 안에 있는 **파일 전부**를 업로드 칸에 끌어다 놓아요.
   - 꼭 *폴더가 아니라 파일들*을 올려요. `index.html`이 맨 위에 보여야 해요.
6. 아래 초록 버튼 **Commit changes**를 눌러요.
7. 저장소 위쪽 메뉴의 **Settings** → 왼쪽 **Pages**로 가요.
8. **Build and deployment**의 **Source**를 `Deploy from a branch`로, **Branch**를 `main` / `(root)`로 고르고 **Save**.
9. 1~2분 뒤 같은 화면 위쪽에 주소가 나타나요.
   `https://내아이디.github.io/my-diary/`
   이 주소가 내 일기장 앱 주소예요. (HTTPS가 자동으로 적용돼요)

### 휴대폰만으로 올리기
1. 받은 zip 파일을 **내 파일** 앱에서 길게 눌러 **압축 풀기**.
2. 크롬에서 github.com에 로그인 → 위 1~3단계로 저장소를 만들어요.
3. 저장소 화면에서 **Add file → Upload files** → **choose your files**를 눌러, 압축을 푼 폴더의 파일을 **모두 선택**해서 올려요.
4. **Commit changes** → 위 7~9단계와 같아요.

### 다른 방법: Netlify Drop (PC)
`app.netlify.com/drop`에 압축을 푼 폴더를 끌어다 놓으면 바로 HTTPS 주소가 생겨요. 주소를 계속 쓰려면 무료 가입을 해 두세요. 이 폴더에는 Netlify용 설정(`netlify.toml`)도 들어 있어요.

## 2. 갤럭시 Z 플립6에 설치하기

1. 휴대폰에서 **크롬**을 열고 위에서 받은 주소로 들어가요.
2. 오른쪽 위 **⋮(점 세 개)** → **홈 화면에 추가** 또는 **앱 설치**를 눌러요.
   (앱의 설정 화면에 **'홈 화면에 앱 설치'** 버튼이 보이면 그걸 눌러도 돼요.)
3. **설치**를 누르면 홈 화면에 '일기장' 아이콘이 생겨요.
4. 아이콘으로 앱을 연 뒤, **설정 → 앱**에서 아래 두 줄이 초록색인지 확인해요.
   - '홈 화면 앱으로 실행 중'
   - '인터넷 없이도 열 수 있어요' (회색이면 인터넷 연결 상태에서 앱을 한 번 닫았다 다시 열어요)
5. **오프라인 확인:** 비행기 모드를 켜고 앱을 열어 일기를 써 보세요. 그대로 저장돼요.

삼성 인터넷 브라우저에서도 메뉴 → **현재 페이지 추가 → 홈 화면**으로 설치할 수 있어요.

## 3. 백업과 복원 (꼭 해 주세요)

기록은 휴대폰 안에만 있어서, 아래 경우에는 사라질 수 있어요.
- 휴대폰을 바꾸거나 초기화할 때
- 크롬 설정에서 **인터넷 사용 기록 삭제 → 쿠키 및 사이트 데이터**를 지울 때
- 홈 화면의 앱을 삭제할 때

**백업하기 (한 달에 한 번 권장)**
1. 앱 **설정 → 백업과 복원 → 전체 백업 (사진·글꼴 포함)**
2. **휴대폰에 저장**을 누르면 `내 파일 → 다운로드`에 `일기장-백업-날짜.zip`이 생겨요.
3. 이 파일을 **구글 드라이브**나 PC에도 한 부 올려 두세요. ('공유해서 보관'이 보이면 바로 드라이브로 보낼 수 있어요.)

**새 휴대폰에서 복원하기**
1. 새 휴대폰에 위 2번대로 같은 주소의 앱을 설치해요.
2. 백업 zip 파일을 새 휴대폰에 내려받아요(드라이브 등).
3. 앱 **설정 → 백업 파일로 복원** → zip 파일 선택 → **복원하기**.
   일기, 날짜, 사진, 태그, 즐겨찾기, 글꼴, 일본어 보관함이 돌아와요. 압축은 풀지 않아도 돼요.

**Claude에서 쓰던 일기 옮기기:** Claude 일기장의 설정 → 전체 백업으로 받은 `.json` 파일도 같은 방법으로 복원돼요.

## 4. 앱 업데이트하기

1. 고친 파일을 같은 저장소에 다시 올려요(같은 이름 파일은 덮어쓰기).
2. **`sw.js` 맨 위의 `VERSION` 숫자를 꼭 올려요.** 예: `diary-v2.0.0` → `diary-v2.0.1`
3. 앱을 열면 '새 버전이 준비됐어요' 안내가 떠요. **지금 업데이트**를 누르면 끝. 일기와 사진은 그대로예요.

---

## 5. 알아 두면 좋은 점과 한계

- **일본어 음성 듣기**는 휴대폰의 음성 엔진을 써요. 소리가 안 나면 휴대폰 **설정**에서 'TTS' 또는 '텍스트 음성 변환'을 검색해 일본어 음성 데이터를 받아 주세요. 음성 데이터가 있으면 인터넷 없이도 들려요.
- **휴대폰 글꼴(갤럭시 글꼴 스타일)**은 웹 앱에 전달되지 않는 경우가 많아요. 그럴 때는 설정에서 TTF·OTF 글꼴 파일을 등록하세요.
- **원고지 모드**에서 붙여넣기는 키보드의 클립보드 버튼으로 해요. 길게 눌러 고르기·붙여넣기는 **줄노트 모드**에서 그대로 쓸 수 있고, 두 모드의 글은 같아요.
- **HEIC 사진**(삼성 '고효율 사진')은 저장은 되지만 일부 화면에서 안 보일 수 있어요. 카메라 설정에서 고효율 사진을 끄면 JPG로 찍혀요.
- 저장 데이터는 **암호화되어 있지 않아요.** 휴대폰 잠금(지문·PIN)을 꼭 켜 두세요. 앱 자체 PIN 잠금은 다음 단계에서 추가할 예정이에요.
- 일본어 문장은 대부분 이 앱을 위해 새로 쓴 문장이며 명언이 아니에요. 속담은 '일본 속담'으로 표시했어요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 화면 |
| `app.css` | 디자인 |
| `app.js` | 일기·원고지·저장·백업 기능 |
| `phrases.js` | 일본어 한마디 220개 (인터넷 없이 표시) |
| `sw.js` | 오프라인 실행을 위한 서비스 워커 |
| `manifest.webmanifest` | 홈 화면 설치 정보(이름·아이콘·색) |
| `icon-*.png`, `maskable-512.png`, `apple-touch-icon.png`, `favicon-32.png` | 앱 아이콘 |
| `netlify.toml`, `_headers` | Netlify·Cloudflare Pages용 HTTPS·보안 설정 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 올리도록 하는 설정 |
